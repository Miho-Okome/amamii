# Google AdSense 申請チェックリスト

## 申請前の必須チェック

```
☑ オリジナルコンテンツが10記事以上ある
☑ 各ページが500文字以上の有用なコンテンツを持つ
☑ サイトがHTTPS（SSL）対応している（Vercelで自動対応）
☑ サイトマップ（/sitemap.xml）が正常に機能している
☑ プライバシーポリシーページ（/privacy）が存在する
☑ お問い合わせページ（/contact）が存在する
☑ スマートフォン表示に対応している
```

## AdSense申請手順
1. https://www.google.com/adsense/ にアクセス
2. サイトURL入力 → パブリッシャーID取得
3. `.env.local` に `NEXT_PUBLIC_ADSENSE_ID=ca-pub-XXXXXXXX` を追加
4. Vercelに再デプロイ
5. AdSense管理画面で「確認をリクエスト」
